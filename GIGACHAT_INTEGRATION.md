# Интеграция GigaChat в KengaAI Studio

## Обзор

KengaAI Studio теперь включает локального AI-помощника на базе модели **GigaChat-20B-A3B-base** от Sber AI. Это позволяет разработчикам работать автономно, без зависимости от внешних API.

## Преимущества

### ✅ Полная автономность
- **Без интернета**: Работает полностью локально
- **Без подписок**: Нет ежемесячных платежей
- **Без лимитов**: Неограниченное количество запросов
- **Конфиденциальность**: Код не покидает вашу машину

### ✅ Специализация
- **Rust эксперт**: Глубокие знания языка и экосистемы
- **KengaAI Engine**: Специфические знания движка
- **3D графика**: WebGPU, Vulkan, OpenGL
- **Игровая разработка**: Архитектура, оптимизация, best practices

### ✅ Производительность
- **Быстрый запуск**: Локальная обработка без задержек сети
- **Оптимизированная модель**: 20B параметров, но только 3B активных
- **Квантизация**: 8-bit для снижения требований к памяти
- **GPU ускорение**: Поддержка CUDA и CPU оптимизации

## Системные требования

### Минимальные
- **RAM**: 8GB
- **Хранилище**: 50GB свободного места
- **ОС**: Linux (ALT Linux, Ubuntu, Fedora)
- **Python**: 3.8+

### Рекомендуемые
- **RAM**: 16GB+
- **GPU**: NVIDIA RTX 3060 / AMD RX 6600 (8GB+ VRAM)
- **Хранилище**: SSD с 100GB+ свободного места
- **Процессор**: 6+ ядер

## Установка

### 1. Автоматическая установка
```bash
# Скачивание и установка всех зависимостей
./setup_alt_linux.sh

# Загрузка модели (40GB)
./download_gigachat.sh
```

### 2. Ручная установка
```bash
# Python зависимости
pip3 install torch transformers accelerate huggingface_hub sentencepiece

# Загрузка модели
python3 -c "
from huggingface_hub import snapshot_download
snapshot_download(
    repo_id='ai-sage/GigaChat-20B-A3B-base',
    local_dir='models/GigaChat-20B-A3B-base'
)
"
```

### Оптимизации

#### Квантизация
- **8-bit quantization**: Экономия 50% памяти
- **Dynamic quantization**: Адаптивная точность
- **CPU оптимизации**: AVX2, SSE4.2

#### Кэширование
- **Token caching**: Повторное использование токенов
- **KV-cache**: Ускорение генерации
- **Memory pooling**: Оптимизация аллокаций

#### Параллелизация
- **Batch processing**: Групповая обработка
- **Multi-threading**: Параллельная генерация
- **GPU оптимизации**: CUDA streams

## Безопасность

### Локальная обработка
- **Zero external calls**: Все данные остаются локально
- **No telemetry**: Отсутствие сбора данных
- **Isolated process**: Python worker в песочнице

### Конфиденциальность
- **Project isolation**: Контекст проекта не покидает машину
- **No cloud storage**: Отсутствие облачного хранения
- **Local history**: История чата сохраняется локально

## Устранение проблем

### Память
```bash
# Если не хватает памяти
export PYTORCH_CUDA_ALLOC_CONF=max_split_size_mb:512
export CUDA_VISIBLE_DEVICES=0
```

### CUDA
```bash
# Проверка CUDA
nvidia-smi
# Установка CUDA toolkit
sudo apt-get install nvidia-cuda-toolkit
```

### Python зависимости
```bash
# Переустановка зависимостей
pip3 uninstall torch transformers
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
pip3 install transformers accelerate
```
