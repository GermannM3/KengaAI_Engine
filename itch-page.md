# Arena One — Kenga Engine Demo

**Arena One** — мини-FPS арена на custom Vulkan движке. 10 волн врагов, 3 типа противников, физика, скрипты, редактор.

## Features

- Vulkan PBR rendering with IBL, shadows, bloom, tone mapping
- Bullet3 physics: rigid bodies, collisions, impulse reactions
- Lua scripting for enemy AI (3 behavior types)
- 10 waves with progressive difficulty
- Score system and kill counter
- ImGui-based editor with scene save/load

## Controls

| Action | Key |
|--------|-----|
| Move | WASD |
| Look | Mouse |
| Shoot | LMB |
| Restart | R |
| Cursor toggle | Tab |
| Pause | Esc |

## System Requirements

- Windows 10/11 (x64)
- Vulkan-compatible GPU (NVIDIA GTX 1060+ / AMD RX 580+)
- 4 GB RAM

## How to Play

1. Extract the zip
2. Run `KengaEngine.exe`
3. Click PLAY in the main menu
4. Survive 10 waves of enemies!
