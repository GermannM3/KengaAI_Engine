# Arena One — Game Design Document (GDD)

Первая полноценная игра на Kenga Engine. RELEASE_PLAN.md, Часть B.

---

## 1. Pitch

**Arena One** — однопользовательская арена: физика, цели, волны противников, одна локация. Игрок управляет камерой от первого/третьего лица, стреляет или толкает объекты, уничтожает ботов и выполняет цель (уничтожить все волны / выжить N секунд). Демонстрирует рендер, физику, анимацию, скрипты и аудио движка.

---

## 2. Core loop (30 секунд)

1. **Действие** — движение (WASD), прицеливание (мышь), выстрел (ЛКМ) или толкание объектов (физика).
2. **Обратная связь** — попадания, звуки, частицы, реакция врагов.
3. **Награда** — враги падают, волна зачищена, переход к следующей волне или победа.
4. **Повтор** — следующий заход или следующая волна.

---

## 3. Механики

### 3.1. Управление

- Камера: FPS (уже в движке), WASD + мышь.
- Выстрел: raycast от камеры по клику ЛКМ; попадание по RigidBody (импульс) или по компоненту Health (урон).
- Опционально: «толкание» — спавн физического объекта по клику (уже есть в движке).

### 3.2. Игрок

- Сущность с компонентами: Camera (или привязка к камере), Player (HP, ammo), возможно Weapon/Shooter (raycast, урон, кулдаун).
- Поражение при HP ≤ 0 (уже проверяется в GameSystem).

### 3.3. Враги

- Компонент Enemy + Health. Поведение: Lua-скрипт или простой FSM (patrol → chase → attack).
- Смерть: при HP ≤ 0 — отключение/удаление сущности или проигрыш анимации; ragdoll опционально.

### 3.4. Цели и победа

- Режим «Уничтожить всех»: 3–5 волн, победа когда все враги убиты.
- Режим «Выжить 60 сек»: таймер, победа по истечении времени.
- Одна арена — одна сцена (scene.json), загрузка из редактора или главного меню.

### 3.5. Окружение

- Арена: пол и стены (уже есть в демо), боксы/препятствия с физикой, при желании — двери на hinge.

---

## 4. Контент и объём

| Элемент | Объём |
|--------|--------|
| Локации | 1 арена |
| Типы врагов | 2–3 (разный HP/поведение) |
| Игрок | 1 тип (камера + оружие/импульс) |
| UI | HUD (HP, волна, цель), экраны победы/поражения |
| Аудио | Шаги, выстрел, попадание, фоновая музыка (1 трек), победа/поражение |

---

## 5. Критерий готовности игры

- Запуск сцены «Arena One», 3–5 волн врагов.
- Победа по условию «все уничтожены» (и при желании «выжить N сек»).
- Поражение при HP ≤ 0.
- Сохранение/загрузка сцены из редактора, стабильный проход без крэшей.

---

## 6. Связь с движком

- **ECS:** Player, Enemy, Health, Weapon/Shooter (или raycast в InputSystem).
- **Сцены:** SceneSerializer, загрузка уровня по имени.
- **Скрипты:** Lua для AI врагов и при необходимости логики волн.
- **Аудио:** расширение AudioSystem (3D, музыка, новые сэмплы).
- **Редактор:** размещение спавн-точек волн, настройка целей в сцене или в конфиге.

Детали реализации — в RELEASE_PLAN.md (милестоуны M2–M3).
