# Как записать видео демо (30–60 сек)

1. **Инструмент:** OBS Studio (бесплатно) или встроенная Windows Game Bar (Win+G в игре).
2. **Длительность:** 30–60 секунд.
3. **Содержание:**
   - Запуск exe, появление окна.
   - Редактор: Hierarchy, создание куба/префаба, Save/Load сцены.
   - Play mode: игрок бегает (WASD), стрельба (ЛКМ), враги атакуют.
   - Победа или поражение, рестарт (R).
   - FPS в ImGui (по желанию).
4. **Экспорт:** mp4, 1080p при возможности.
5. **Публикация:** YouTube (unlisted) или Google Drive, вставь ссылку в README.md в раздел «Видео демо».
