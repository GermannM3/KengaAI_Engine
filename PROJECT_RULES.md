# PROJECT_RULES.md — Неизменные правила и цели проекта

> Обязательно читай полностью каждый раз перед генерацией кода.

## Название проекта

Kenga Engine (рабочий код: KengaEngine) — самописный игровой движок на современном C++ для AAA-игр. Цель — в долгосрочной перспективе заместить функционал Unreal Engine 5 по ключевым направлениям (рендеринг, физика, редактор, мультиплеер, инструменты).

## Главная цель проекта

Создать модульный, высокопроизводительный, расширяемый игровой движок на C++20/23, способный запускать AAA-игры с высоким качеством графики, физики и геймплея. Движок полностью под контролем человека (Kenga), AI (Cursor) — исполнитель.

## Ключевые принципы (нарушение = откат)

1. **C++20/23** — основной язык. concepts, ranges, modules (когда стабильно), coroutines (осторожно), std::expected, std::span.
2. **Модульная архитектура** — каждый модуль в отдельной папке с собственным CMake. Минимальная связанность.
3. **ECS** — основная модель объектов и геймплея.
4. **Vulkan** — основной graphics backend (DirectX 12 — альтернатива для Windows).
5. **No garbage collector** — максимальная производительность, custom allocators где нужно.
6. **Cross-platform** — сначала Windows, потом Linux, macOS, консоли.
7. **Тестируемость** — unit-тесты (GoogleTest) для каждого модуля.
8. **Документация** — Doxygen-style в коде, README в каждой папке.
9. **Кодстайл:** snake_case, PascalCase для типов, 4 пробела, clang-format, const/constexpr, RAII, избегать raw pointers.
10. **Запреты:** exceptions для flow control, лишние зависимости, монолитный код, смена архитектуры без согласования.
